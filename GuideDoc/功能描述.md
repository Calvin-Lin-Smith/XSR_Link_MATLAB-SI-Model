

- `src/`：模型和 DSP 实现，GUI 直接调用。
- `test/`：自动测试脚本，部分由 GUI 按钮调用。
- `gui/`：参数编辑、模型浏览、测试调度和结果展示。
- `results/`：CSV、MAT、JSON、JUnit 和图片输出。

这种方式避免在 GUI 中复制模型代码。修改 `D2DPHY`、DSP 或测试函数后，GUI 会直接使用新版代码。

**GUI 当前可执行的测试**

1. **Run x8 Link**

使用 GUI 中的全部 Model Parameters 构造完整 x8 D2D PHY：

```text
Raw PCS → TX PMA → 8×TX Lane → 8×Channel
        → 8×RX Lane → RX PMA → BER Checker
```

输出：

- Aggregate BER
- Error count
- Measured bits
- 最佳采样 phase
- 对齐 delay
- CTLE AGC gain
- 任意内部节点眼图或波形

2. **Loss Sweep**

使用 GUI 中填写的 `Loss points`，逐点修改：

```matlab
channel.lossNyq_dB
```

生成损耗与 BER 曲线，并输出：

```text
results/gui_loss_sweep.csv
```

3. **CTLE Sweep**

使用 `CTLE boost` 输入向量，逐点扫描：

```matlab
rxPma.lane.ctleBoost_dB
```

用于观察 CTLE 高频提升对 BER 和眼图恢复的影响。

4. **RJ Sweep**

使用 `RJ RMS` 输入向量扫描：

```matlab
link.rjUI_rms
```

验证随机抖动增加时 BER 的变化。

5. **CDR Sweep**

使用 `CDR bandwidth` 输入向量，自动将时钟模式改成 `cdr`，扫描：

```matlab
link.cdrBw
```

输出：

- BER
- residual phase RMS
- CDR 最优带宽趋势

6. **FFE + CTLE Scan**

使用 GUI 中的：

```text
FFE pre
FFE post
CTLE boost
```

执行组合扫描。主游标自动计算为：

```matlab
main = 1 - pre - post
```

输出每组：

- pre
- post
- main
- CTLE boost
- BER

结果写入：

```text
results/gui_eq_sweep.csv
```

7. **Behavior Suite**

直接调用 `test/behavior_tests.m`，包含：

- BER 随信道损耗增加
- CTLE 降低 BER
- CTLE 改善统计眼高
- RJ 增大导致 BER 上升
- CDR 存在内部最优带宽
- CDR residual phase RMS 趋势

这套测试采用脚本内预先校准的稳定测试点，不使用 GUI 中的 sweep 向量。

8. **Standard T1–T9**

直接调用 `test/run_all_tests.m`，包括：

- **T1**：NRZ/PAM4、28/56 GBaud、0/4/8/10 dB 的 16 种眼图组合
- **T2**：BER 随 0–10 dB 损耗增加
- **T3**：围绕最佳采样相位的经验 bathtub 曲线
- **T4**：受约束 FFE/CTLE 扫描与 PRE/POST dB 校验
- **T5**：CTLE 对 BER 和眼高的改善
- **T6**：PRBS7、PRBS15、PRBS31、PRQS10 surrogate 与精确误码注入
- **T7**：同波特率下 NRZ/PAM4 噪声敏感度对比
- **T8**：CDR BER 与 residual phase 的内部最优点
- **T9**：x8 shallow、serial-lane 和双端点 die-to-die loopback

输出包括：

```text
results/summary.csv
results/junit.xml
results/manifest.json
results/probes.json
results/regression.mat
results/T1_eye_*.png
results/T3_bathtub.png
```

**目前没有独立 GUI 按钮的脚本**

以下三个脚本仍只能从 MATLAB 命令行独立执行：

```matlab
test_dsp
test_leaf_classes
test_hierarchy
```

它们分别测试：

- DSP API 的严格恒等、映射和 dB 精度
- 9 个叶子类的 `configure/run/dump`
- 完整 x8 层级、理想 BER=0 和白盒探针

因此，准确结论是：**所有模型代码都能被 GUI 使用，主要行为测试和 T1–T9 已接入 GUI，但三个底层 smoke test 还没有独立 GUI 按钮。**
