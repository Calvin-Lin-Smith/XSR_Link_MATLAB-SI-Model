# VLSI2024 XSR 功能矩阵与边界

本页是导航级功能矩阵；可执行步骤以 [VLSI2024 XSR 完整复现与演示指南](VLSI2024_XSR_SerDes_完整复现与演示指南.md) 为准。所有 BER/eye 数值都是有限样本行为输出，不能替代 3nm 电路、硅片或 sign-off。

## 功能矩阵

| 功能 | 真实入口 | 输入 | 输出/证据 | 支持状态 |
|---|---|---|---|---|
| Paper profile | phyConfig('vlsi2024_xsr' / 'vlsi2024_xsr_typical' / 'vlsi2024_xsr_ideal') | profile 名 | 嵌套 cfg、paper facts、model/debug schema | 支持；VLSI Typical/Ideal |
| 分层 x8 链路 | D2DPHY(name,nLane).configure(cfg); .run() | link、rawPcs、txPma、rxPma、channel | rxBits、errCnt、nMeasured、ber、aggregateBer；对象白盒节点 | 支持；PAM4/NRZ DSP |
| Raw PCS | RawPcs.run/check | PRBS7/15/31 或 PRQS10_SURROGATE、errInject | tx/reference bits、rx bits、误码计数 | 支持；PRQS 为 surrogate |
| Signed 3/6-tap FFE | dspFfeVector；Ffe/TxLane | tapCoeffs、tapOffsets、normalize、currentConstraint | FFE 波形与 tapMeta | 支持；系数为 model-selected |
| Driver / DAC | Driver.run | amplitude、enableDacQuantization、dacLevels、targetSwing、gainError、enableSwingCalibration | TX pad、dacMeta | 支持行为量化；不等同 SST 电路 |
| Analytic IL channel | dspChannel / Channel | mode=analytic_il、refFreq_GHz、baud_GBd、lossAtRef_dB、poles | channel waveform、28 GHz measured IL | 支持；无 Touchstone/S 参数 |
| AC / termination | Afe.run；dspAcCouple | AC/DC、enableAcPre/Post、corner、initialState、termGain | termOut、acPreOut、acPostOut、long-run offset | 支持；一阶高通抽象 |
| Single-stage CTLE | dspCtle / Ctle | paper_grid、boost、grid、fz | ctleRaw、ctleOut、applied boost | 支持 0:0.2:6 dB；零极点为假设 |
| Sampler roles | Slicer.run | 4 branches、12/4/4 counts、level shifts、thresholds、offset | data/edge/spare、quarterRate、levelShiftedSamples | 支持行为角色；不是 20 个电路实例 |
| BB-CDR / PI | dspBbCdr、dspPiClock、RxLane | phase、gain、nCodes、lock window/tolerance、mismatch | cdrTrace、PI trace、lockIndex、residual phase | 支持 reference-free decision-directed |
| Offline training | run_vlsi2024_xsr('debug_link',…) | 五个 stage toggles、每 stage UI budget | stageTrace、stateTrace、trainedCfg | 支持 bounded behavior |
| Final post-lock measurement | debug_link 内部 final pass | all-lane lock、postLockWaitUI、skipUI | global measurementStartUI/sample、performance、BER validity | 支持；no-lock/insufficient 无效 |
| Calibration/adaptation | run_vlsi2024_xsr('adaptation',…) | nBits、Config、enablePaperAdaptation | 五状态 adaptation trace、CTLE candidate trace | 支持 bounded objective；非 BER 优化 |
| Paper baseline | run_vlsi2024_xsr('baseline',…) | nBits、Config | baseline metrics、CDR/PI trace、baseline probes | 支持；正式结果写盘 |
| Static checkpoints | run_vlsi2024_xsr('static_checkpoint',…) | nBits、Config | IL、3/6-tap、AC/CTLE、static summary | 支持；外层 Config 不能改变内部默认子运行 |
| Paper full regression | run_vlsi2024_regression('full',…) | nBits 或 name/value nBits | 全部 VLSI artifacts、legacy_t1_t9、summary | 支持；耗时由样本数决定 |
| GUI | D2DWorkbench、launchD2DWorkbench | VLSI paper table、paper actions | in-memory Debug 或 results 目录 | paper-only；不提供 generic GUI actions |
| Simulink diagram | buildD2DSimulinkModel | Config、ModelName、ModelPath、Open、Save、Overwrite | 生成 SLX、模型 workspace d2dCfg | 支持展示/临时验证；算法源仍是 MATLAB |
| Artifact validation | validate_vlsi2024_artifacts(root[, 'ignore_summary']) | 结果目录 | ok、detail | 支持 schema、字段、UCB、legacy 文件检查 |
| 旧兼容回归 | run_all_tests([outDir]) | 可选输出目录 | T1–T9 CSV/PNG/MAT/JSON/JUnit | 仅 CLI 兼容路径 |

## 输入输出和测量口径

### Core D2DPHY

主数据流为 RawPcs → TxPma x8 → Channel x8 → RxPma x8 → RawPcs.check。D2DPHY.run 在 channel 后按 link.seed 和 snr_dB 加噪；RX 支持 legacy reference alignment、manual phase 或 formal BB-CDR。D2DPHY 结果字段为 rxBits、errCnt、nMeasured、ber、aggregateBer。

### Paper debug link

run_vlsi2024_xsr('debug_link',nBits,'Config',cfg) 返回 mode、status、requestedCfg、trainedCfg、appliedCfg、model、result、rawResult、stateTrace、ctleTrace、stageTrace、trainedParameters、laneLockUI、laneLocked、fullLockTrace、trainingEndUI、totalTrainingBudgetUI、berStartUIInFinalPass、measurementStartUI、measurementStartSample、postLockWaitUI、totalWaitedUI、performance、requiredLaneLockUI、berValid、effectiveCdrEnabled、preLockSentinelApplied 和 preLockSentinel。

启用 CDR 且全 lane 锁定时：

~~~text
latestLockUI = max(laneLockUI)
measurementStartUI = max(originalSkipUI, latestLockUI + postLockWaitUI)
measurementStartSample = measurementStartUI*sps + 1
~~~

performance 只保留该 global latest-lock window 之后的 CTLE、data/edge/spare、level-shifted samples、eyeHeight 与 isiMargin。没有锁定、没有足够 final bits 或 CDR 关闭时，Result.berValid=false，不能拿 NaN/空统计作性能结论。

## 支持与不支持

支持：

- MATLAB R2024b 下的 x8 PAM4 paper profile、有限 NRZ/PAM4 DSP 对照、PRBS31；
- signed 3/6-tap FFE、206-level 行为 DAC、analytic IL 0.5–10 dB 扫描；
- AC termination/pre/post、单级 CTLE 0–6 dB/0.2 dB、sampler role probes；
- reference-free decision-directed BB-CDR、64-code PI 行为、lock/PI/residual trace；
- 独立 training toggle、UI budget、manual phase 保留、统一 post-lock window；
- baseline/static/adaptation/full artifact 及 legacy T1–T9 CLI 兼容回归。

不支持或不声称支持：

- 完整 9.8–113 Gb/s 的硅后覆盖、真实晶体管/SST DAC、T-coil/ESD、电源/PVT 或 DLL/PI 电路；
- 真实 package/interposer Touchstone、反射/回损、NEXT/FEXT MIMO 传播、lane-to-lane crosstalk；
- 论文未公开的 FFE 系数、CTLE 零极点/噪声、完整 CDR transfer function；
- 无限长 BER、有限样本零误码对论文 <1e-12/<1e-14 的证明；
- 功耗预测、0.9 pJ/b 复现、面积或 silicon calibration sign-off；
- GUI 中 generic profile、旧扫描按钮或把 T1–T9 当 paper action。

## Paper facts 与 model behavior

| 类别 | 当前记录 | 文档口径 |
|---|---|---|
| 论文事实 | 8 lanes + PLL、3/optional 6-tap、206-level SST DAC、单级 CTLE 0–6 dB/0.2 dB、20 sampler roles、2 DLL + PI/BB-CDR、PRBS31、1–80 mm/0.5–10 dB、NEXT/FEXT −40/−38 dB @28 GHz、约 194 fs PLL+TX integrated context、0.9 pJ/b quote | 只作为 architecture/context；不当作模型测得值 |
| 模型行为 | 112.5 Gb/s/56.25 GBd baseline、sps=16、2^18 bit、SNR/RJ/DJ、analytic IL、3/6 tap preset、64-code PI、锁定条件、training budget、eye/BER/UCB | 由 cfg 和代码决定；每次结果保留 seed/sample context |
| 当前验证 | 仓库保存的 results/vlsi2024_xsr/regression_summary.csv 将 baseline、static、adaptation、legacy_t1_t9、artifact_schema 记录为 pass；test_stage_h.m/test_vlsi2024_* 提供源码级契约 | 这是保存的证据状态；文档更新本身未重跑 full regression |
| 统计限制 | errors、measured_bits、empirical_BER 与 ber_upper_95 | 0 error 时 UCB=3/N；不写成真实 BER 上限之外的硅结论 |
