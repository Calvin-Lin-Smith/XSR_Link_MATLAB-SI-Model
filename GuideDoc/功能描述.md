# VLSI2024 XSR GUI 功能

GUI 复用现有三列布局、层级树、参数表、动作区、白盒探针和结果区，但只提供 VLSI2024 XSR paper workflow。backend 的 generic profiles 与 legacy CLI tests 仍保留在 MATLAB 命令行，不作为 GUI 入口。

## Paper presets and controls

GUI 启动时加载 `VLSI Typical`。`VLSI Ideal` 保持相同 `VLSI2024_XSR_3nm` identity/schema，仅关闭 channel loss、noise、jitter、DAC quantization 和 PI mismatch，作为 debug reference。两套 preset 都保留 signed FFE、DAC、analytic IL、AC/CTLE、sampler roles、BB-CDR/PI 和结果字段。

配置表可编辑 rate/sample/seed/result、FFE offsets/coefficients/current constraint、DAC、IL@28GHz、AC termination/coupling、CTLE、sampler offsets/thresholds、training toggles、CDR/PI 和 `postLockWaitUI`。preset selection 只重填初值；cell edit 后的 requested cfg 由下一次 **Run x8 Link** 消费。无效数值、signed FFE offsets 或越界 CTLE 输入会被拒绝并保留上一个有效 requested cfg。

## Paper actions

- **Run x8 Link**：按 RESET → enabled startup/clock/sampler/CTLE/FFE training → formal x8 decision-directed CDR → lock/post-lock wait → MISSION_TRACK 的行为顺序运行 in-memory debug link。不调用 full regression，也不覆盖 `results/vlsi2024_xsr`。
- **VLSI2024 Baseline**：调用现有 paper baseline runner。
- **Static A-D / FFE / IL / AC-CTLE**：调用现有 static checkpoint runner。
- **BB-CDR / PI / Jitter Evidence**：调用 bounded paper regression evidence runner。
- **Calibration / Adaptation**：调用现有 adaptation runner。
- **Full VLSI2024 Regression**：调用完整 paper regression；正式 release gate 再运行默认 x8 规模。

Run x8 Link 返回 requested/trained/applied cfg、每个 stage 的 executed/skipped 状态与 offline UI budget、每 lane lock UI、training end、final-pass BER start、total waited、measured bits 和 `trainedParameters` 表。`trainedParameters` 保存 full path、requested/trained/applied、residual、constraint 和 unit。

## Measurement boundary

启用 CDR 时，要求所有 lane lock；aggregate BER/eye/margin 在 no-lock 或样本不足时标为 invalid。所有 lane 共用
`measurementStartUI = max(originalSkipUI, latestRequiredLaneLockUI + postLockWaitUI)`，并以
`measurementStartSample = measurementStartUI*sps+1` 截取 eye、eye height、sample-level distribution、ISI/margin 和 BER。完整 CDR acquisition/lock trace 与明确标注的 raw debug waveform 可保留，但 pre-lock samples 不进入 performance 结论。关闭 CDR 只产生 `debug_no_cdr`，不属于 formal paper result。

Simulink/core DSP 仍由现有 MATLAB API 提供；GUI 只负责 paper 参数编辑、runner 调用和结果呈现。
