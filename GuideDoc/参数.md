配置文件位于 `src/config/phyConfig.m`。

**链路参数**

| 参数              |  默认值 | 具体意义                                                     |
| ----------------- | ------: | ------------------------------------------------------------ |
| `link.modulation` |  `PAM4` | 调制方式。PAM4 每个符号承载 2 bit，56 GBaud 对应单 lane 112 Gb/s 原始速率。 |
| `link.baud_Gbps`  |    `56` | 符号率，单位 GBaud。当前主要作为链路工作模式和报告参数。     |
| `link.sps`        |    `16` | 每 UI 的离散采样点数。越高时域分辨率越高，但仿真更慢。       |
| `link.nBits`      | `12000` | 每条 lane 本次生成和检查的比特数量。样本太少时只能观察有限 BER。 |
| `link.skipUI`     |    `32` | BER 统计时跳过的启动 UI，用于避开信道、CTLE 和滤波器初始暂态。 |
| `link.snr_dB`     |    `28` | 接收链路信噪比。越低，幅度噪声越大；`inf` 表示不加噪声。     |
| `link.rjUI_rms`   | `0.005` | 随机抖动 RMS，单位 UI，相当于 0.5% UI RMS。                  |
| `link.djUI_pp`    |  `0.02` | 正弦确定性抖动峰峰值，单位 UI，相当于 2% UI pp。             |
| `link.djFreq`     | `0.001` | DJ 归一化频率，单位 cycle/UI；`0.001` 表示周期约为 1000 UI。 |
| `link.cdrBw`      |   `0.1` | 归一化 CDR 环路带宽，仅 `clockMode='cdr'` 时参与恢复时钟计算。 |
| `link.seed`       |    `42` | 随机噪声和抖动种子，用于保证测试结果可复现。                 |

**Raw PCS 参数**

| 参数               |   默认值 | 具体意义                                                     |
| ------------------ | -------: | ------------------------------------------------------------ |
| `rawPcs.pattern`   | `PRBS31` | 发送测试码型。当前还支持 PRBS7、PRBS15 和明确标记的 PRQS10 surrogate。 |
| `rawPcs.errInject` |      `0` | 在测量区间主动翻转的比特数量，用于检查误码计数器。正常链路保持为 0。 |

**TX PMA / FFE 参数**

| 参数           |  默认值 | 具体意义                                               |
| -------------- | ------: | ------------------------------------------------------ |
| `txEqMain`     |  `0.98` | FFE 主游标幅度。                                       |
| `txEqPre`      |  `0.01` | 前游标去加重幅度；模型中的实际 tap 符号为 `-pre`。     |
| `txEqPost`     |  `0.01` | 后游标去加重幅度；模型中的实际 tap 符号为 `-post`。    |
| `ffeNormalize` | `false` | 是否自动归一化 FFE tap。`false` 表示直接使用所填 tap。 |
| `amplitude`    |     `1` | TX Driver 的归一化输出幅度。PAM4 标称电平由此缩放。    |

当前 FFE tap 等效为：

```text
[-0.01, 0.98, -0.01]
```

这是轻度均衡，保留实际 TX 去加重行为，同时不会过度放大噪声。

**信道参数**

| 参数                 | 默认值 | 具体意义                                                     |
| -------------------- | -----: | ------------------------------------------------------------ |
| `channel.lossNyq_dB` |    `8` | 信道在 Nyquist 频率处的插入损耗。8 dB 会产生明显 ISI，但仍可由 CTLE 恢复。 |
| `channel.poles`      |    `3` | 解析低通信道的级联极点数。越高，滚降和时域拖尾通常越明显。   |

**RX PMA 参数**

| 参数           |      默认值 | 具体意义                                                     |
| -------------- | ----------: | ------------------------------------------------------------ |
| `ctleBoost_dB` |         `8` | CTLE 高频相对低频提升量，用于补偿 8 dB 信道高频损耗。        |
| `ctleFz`       |      `0.25` | CTLE 零点频率，单位 cycle/UI；决定高频提升开始出现的位置。   |
| `termGain`     |         `1` | RX 端接块的归一化插入增益。小于 1 可模拟端接损耗。           |
| `clockMode`    | `forwarded` | 时钟模式。D2D 默认采用源同步 forwarded clock；改成 `cdr` 后启用带宽相关恢复模型。 |

**默认配置实测**

使用最终默认参数运行：

```text
BER          = 2.513826e-4
Errors       = 3
Measured     = 11934 bits
Eye height   = 0.938878
```

这表示链路存在实际损耗、噪声、RJ、DJ 和轻度均衡，但 PAM4 三个眼仍可正常判决。该 BER 是当前有限样本、无 FEC 行为模型下的 pre-FEC 结果，不是硅片合规性指标。
